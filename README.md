# R-SODIUM Precision TouchPad Configurator

R-SODIUM 触摸板的 Windows 配置工具，支持读取、编辑、应用设置及保存后读回校验。

在“设备设置 → 其他设置”中可设置自动切换连接，以及 **“触发自定义手势时开启振动反馈”**。

- 自定义手势振动反馈默认开启，作用于单点和边缘自定义动作；关闭后手势功能保留，普通按压和系统触觉反馈沿用原有设置。
- 修改后点击应用。设备已保存的关闭值在重新读取、重连后保留，Windows 11 下也可编辑此选项。
- 该开关需要支持 RSTP 配置 v5 和能力位 0x2000 的固件。旧固件只保留预览，界面会提示，保存其他设置时不会写入该预览值。
- 演示模式只模拟内存中的配置读写，不会触发真实振动。本仓库不含固件源码，真实振动和断电保存需固件配套实现。

协议与固件对接：[FIRMWARE.md](FIRMWARE.md)、[HID 协议](docs/hid-protocol.md)。
